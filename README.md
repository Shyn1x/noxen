# NOXEN — Winter 2027

Fictional fashion e-commerce portfolio demo for Lomenti. Dark purple neon / restrained liquid-glass direction.

## Local preview

Open `index.html` in a browser (or serve this folder with a static HTTP server). No dependencies or backend required.

## Implemented

- Responsive landing page with WINTER 2027 hero
- Interactive product illustration with 7 color variants and sizes
- Simulated rotation by dragging or using view buttons
- Demo cart counter and accessible status messages
- Reduced-motion support

## Still to build

Real distinct models and licensed fashion photography; 10-item catalog with filters/sorting/favorites; per-color multi-angle image sets and real 360 frames; full visual and functional browser QA.

**Demo only:** no real checkout, availability, performance or thermal claims. Do not deploy/publish without owner approval.
